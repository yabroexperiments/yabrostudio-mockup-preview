# yabrostudio.com — Home page mockup preview

Visual prototype of yabrostudio.com (阿伯工作室). Pure HTML + CSS, framework-agnostic.

- `index.html` — Traditional Chinese (default)
- `en.html` — English

Live preview via GitHub Pages.

Shorter than albertchen.xyz: no Now or Notes sections. Sections are Hero → 作品 (Projects, 3 tiles) → 關於 (About + contact merged) → Footer.

The actual production site will be built on WordPress + Divi 5 with Polylang (zh-TW default + EN secondary), forking the albertchen.xyz child theme.
